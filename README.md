# 基于 HTML 的文件加密解密工具

一个纯浏览器端的文件加密/解密工具，单文件、无需联网、无需安装、开源可验证。

## 在线使用

**直接访问：[https://hzxs163.github.io/encrypt/](https://hzxs163.github.io/encrypt/)**

也可以下载页面中的 `index.html` 到本地，双击离线使用，不依赖任何网络服务。

## 功能特点

- **纯前端加密**：所有加密计算都在你的浏览器本地完成，文件不会上传到任何服务器
- **单文件部署**：整个工具就是一个 HTML 文件，可以随意保存、拷贝、分享
- **零依赖**：不需要安装任何软件，现代浏览器（Chrome / Edge / Firefox / Safari）直接打开就能用
- **零知识**：我们看不到你的文件，也看不到你的密码——服务器只是静态托管了一个网页
- **离线可用**：下载后断网也能正常加解密

## 加密算法

| 项目 | 参数 |
|------|------|
| 密钥派生 | PBKDF2-HMAC-SHA512 |
| 迭代次数 | 16,777,216 次（2²⁴） |
| 随机盐值 | 32 字节密码学安全随机数 |
| 文件加密 | AES-256-GCM（带完整性校验） |
| 密钥封装 | AES-256-CBC |

> 安全性完全取决于你使用的密码强度。建议使用 16 位以上、包含大小写字母、数字和符号的随机密码。

## 使用方法

### 加密文件
1. 打开网页，将文件拖入虚线框（或点击选择文件）
2. 输入密码并确认
3. 可选：展开高级选项设置文件名、提示语等
4. 点击「保存」，下载加密后的文件

### 解密文件
1. 将加密后的文件拖入
2. 输入加密时设置的密码
3. 点击保存，即可还原原文件

## 常见问题

**Q：这个工具安全吗？**
A：算法本身是行业标准（AES-256 + PBKDF2），没有已知后门。但安全性取决于密码强度——弱密码再强的算法也挡不住暴力破解。

**Q：我的文件会被上传吗？**
A：不会。所有加密解密都在你的浏览器内存中完成，文件数据从不离开你的电脑。打开开发者工具的 Network 面板也能看到没有任何上传请求。

**Q：为什么要下载离线版？**
A：在线版依赖本页面一直可用。下载 HTML 到本地后，即使本网站关闭，你仍然可以随时用它加解密。
